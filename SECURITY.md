# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in BurpGate, please report it privately.

**Do not open a public GitHub issue.**

Send details to the repository owner or open a private advisory at:
https://github.com/Nixon-H/BurpGate/security/advisories/new

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

- BurpGate extension code
- MCP server implementation
- Configuration handling and credential storage

## Out of Scope

- Burp Suite itself (report to PortSwigger)
- Dependencies with known CVEs (use `dependabot` alerts)
